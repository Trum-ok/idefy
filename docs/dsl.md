# Язык

Формат — YAML. Машиночитаемая схема выгружается командой `idefy schema`.

## Корень

| Поле         | Тип     | Обязательно | Значение                        |
|--------------|---------|-------------|---------------------------------|
| `version`    | `1`     | нет         | версия формата, пока только `1` |
| `model`      | объект  | да          | паспорт модели                  |
| `activities` | список  | да          | функции                         |
| `arrows`     | список  | нет         | ручные уточнения стрелок        |

Посторонние поля запрещены: опечатка в имени поля — это ошибка разбора, а не
молча проигнорированная строка.

## `model`

| Поле        | Тип    | Обязательно | Значение                                      |
|-------------|--------|-------------|-----------------------------------------------|
| `name`      | строка | да          | имя модели, попадает в `.rsf`                 |
| `author`    | строка | нет         | автор, попадает в `.rsf`                      |
| `purpose`   | строка | нет         | цель модели; без неё `W002`                   |
| `viewpoint` | строка | нет         | точка зрения; без неё `W002`                  |

Цель и точка зрения задают границы модели. Без них декомпозиция расползается:
непонятно, что в модели лишнее, а что забыто.

## `activities`

| Поле        | Тип             | Обязательно | Значение                     |
|-------------|-----------------|-------------|------------------------------|
| `id`        | строка          | да          | идентификатор функции        |
| `name`      | строка          | да          | имя-действие                 |
| `input`     | список строк    | нет         | входы, слева                 |
| `control`   | список строк    | да по сути  | управления, сверху           |
| `output`    | список строк    | да по сути  | выходы, справа               |
| `mechanism` | список строк    | нет         | механизмы, снизу             |

`control` и `output` формально необязательны в схеме, но их отсутствие — ошибки
`E004` и `E003`: функция без управления неуправляема, функция без выхода
бесполезна.

Имена стрелок обрезаются по краям (`strip`) и дедуплицируются внутри одного
списка. Пустое имя — ошибка разбора.

### Идентификаторы

Идентификаторы иерархические и самоописывающие: родитель выводится из имени.
Отдельного поля `parent` нет.

```
A0            контекстная функция
├── A1        её декомпозиция
│   ├── A11
│   └── A12
├── A2
└── A3
```

Формат — буквенный префикс и номер: `A0` для корня, дальше цифры от 1 до 9 на
каждом уровне. `A21` без `A2` — ошибка `E002`.

Порядок блоков на диаграмме задаётся сортировкой по `id`, а не порядком записи
в YAML: перестановка строк в файле не должна менять картинку.

## Разрешение стрелок

Стрелки не объявляются явно. Для каждой диаграммы (набора детей одного родителя)
компилятор сопоставляет имена в ICOM-списках.

| Ситуация                                                              | Результат                                              |
|-----------------------------------------------------------------------|--------------------------------------------------------|
| Имя есть в `output` соседа и во `input`/`control`/`mechanism` другого | внутренняя стрелка между блоками                       |
| Имя совпадает с ICOM родителя в той же роли                           | граничная стрелка от рамки или на рамку                |
| Имя выхода не потребляется никем и нет у родителя                     | ошибка `E006`, лечится `to: external` в блоке `arrows` |
| Один выход потребляется несколькими блоками                           | ветвление, это валидно                                 |
| Одно имя стоит в `output` у нескольких блоков                         | слияние, это валидно                                   |
| Стрелка идёт к блоку с меньшим номером                                | обратная связь, отдельный маршрут                      |

Сопоставление строгое: точное совпадение строки после обрезки пробелов, регистр
учитывается. Расхождение в написании — это `E006`, а не повод для нечёткого
поиска: молчаливое склеивание похожих имён хуже явной ошибки. Подсказка к `E006`
покажет похожее имя, если оно есть.

Родитель источником не считается никогда: он задаёт рамку диаграммы, поэтому
совпадение с его ICOM даёт граничную стрелку, а не конфликт с блоком, выдающим
то же имя. Одно имя может одновременно быть внутренней стрелкой и уходить за
рамку — это обычное ветвление.

Ветвление и слияние рисуются одной стрелкой с развилкой и подписываются один
раз: в IDEF0 это одна сущность.

## `arrows`

Необязательный блок для случаев, где авторазрешения не хватает.

```yaml
arrows:
  - name: "Список недостающих документов"   # имя, как в ICOM-списках
    from: A1                                # id функции или external
    to: external                            # id функции или external
    role: input                             # необязательно: роль на приёмнике
    tunnel: dest                            # none | source | dest | both
```

| Поле     | Значение                                                           |
|----------|--------------------------------------------------------------------|
| `name`   | имя стрелки                                                        |
| `from`   | id функции-источника или `external` — рамка диаграммы              |
| `to`     | id функции-приёмника или `external`                                |
| `role`   | роль на приёмнике, когда имя стоит у него в нескольких списках     |
| `tunnel` | где стоит туннель: нигде, у источника, у приёмника или с обеих сторон |

Запись либо уточняет уже выведенную стрелку, либо объявляет ту, которая из
ICOM-списков не выводится. Стрелка адресуется тройкой `name` + `from` + `to`;
если такой стрелки нет и объявление её не создаёт, это `E006`.

Хотя бы один конец должен быть идентификатором функции, и оба конца должны
лежать на одной диаграмме.

### Туннели

Туннель ставится там, где стрелка есть на одном уровне и намеренно отсутствует
на соседнем. Типичный случай — `E007`: ICOM родителя, который не подхватывает
ни один блок декомпозиции. Помечается на диаграмме родителя, на том конце,
которым стрелка касается блока:

```yaml
arrows:
  - name: "Инструкция"
    from: external
    to: A1
    tunnel: dest
```

## Диагностики

`idefy validate` возвращает список диагностик: код, уровень, место и, по
возможности, подсказку. Ошибки дают код возврата 1, предупреждения — 0.

### Ошибки

| Код  | Правило                                                              |
|------|----------------------------------------------------------------------|
| E001 | Дублирующийся `id`                                                   |
| E002 | Нет родителя для `id` (например, `A21` без `A2`)                     |
| E003 | У функции нет ни одного выхода                                       |
| E004 | У функции нет ни одного управления                                   |
| E005 | В декомпозиции больше 8 блоков                                       |
| E006 | Стрелка не разрешена: имя не найдено ни у соседей, ни у родителя     |
| E007 | ICOM родителя не подхвачен ни одним ребёнком и не помечен туннелем   |
| E008 | Имя стоит и в `output`, и во входном списке одной функции (петля)    |
| E009 | Отсутствует контекстная функция `A0`                                 |
| E010 | В модели больше одной контекстной диаграммы                          |

### Предупреждения

| Код  | Правило                                                          |
|------|------------------------------------------------------------------|
| W001 | В декомпозиции меньше 3 или больше 6 блоков                      |
| W002 | Не заполнены `purpose` или `viewpoint`                           |
| W003 | Имя функции не начинается с глагола в неопределённой форме       |
| W004 | Функция не декомпозирована, хотя у неё больше 5 ICOM-стрелок     |
| W005 | Обратная связь пересекает больше двух блоков                     |
| W006 | Одно имя потребляется разными блоками в разных ролях             |
